# 捐赠收款码

把你的微信/支付宝收款二维码图片放到这个目录：

- `wechat.png` — 微信收款码（建议 240×240，PNG）
- `alipay.png` — 支付宝收款码（建议 240×240，PNG）

## 推荐

- 用手机截屏收款码 → 去 [草料二维码解码器](https://cli.im/deqr) 解出链接
- 用任意二维码生成器重新生成 240×240 的 PNG（白底居中）

## 命名

- 文件名必须小写：`wechat.png` / `alipay.png`
- 格式：PNG（推荐，支持透明）
- 尺寸：200-300px 方形

> 注意：`assets/donate/*.png` 已在 `.gitignore` 中被排除（双重保险）。
> 但你的 `wechat.png`/`alipay.png` 不会被 ignore（你可以决定是否上传）。
